## Featured project

### Trading Copilot

A personal options-trading research application that turns bullish and bearish workbook inputs into a secure, traceable analysis workflow.

- Built with Next.js, TypeScript, Supabase, and PostgreSQL
- Imports and validates Excel stock lists before saving them
- Uses authenticated ownership, row-level security, audit records, and transactional imports
- Preserves the current bullish and bearish candidate sets for evaluation
- Preparing for live stock and options data through the Charles Schwab Trader API

The source repository is private while active development is underway.
